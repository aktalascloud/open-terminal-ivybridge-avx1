# Open Terminal for Ivy Bridge · AVX1

A standalone Windows service that exposes terminal and native agent tools to Open WebUI. It covers Ivy Bridge AVX1 and includes bounded output and identity-scoped tool results.

**Quick start.** Extract the ZIP and run `Install.cmd`. For a source build, use `Build.cmd status` and `Build.cmd build` with Python 3.12+, Git and GitHub CLI. [Applied patches](patches/README.md).

**Evidence.** The November 17 Windows release ships a 2.59 MB ZIP, with its SHA-256, exact source and patch links. Build records cover selected checks without needing model weights.

## Русский

Отдельный сервис Windows для терминала и инструментов нативных агентов Open WebUI. Подходит для Ivy Bridge AVX1, ограничивает историю вывода и привязывает результаты инструментов к пользователю.

**Запуск.** Распакуйте ZIP и запустите `Install.cmd`. Для сборки из исходников выполните `Build.cmd status` и `Build.cmd build` с Python 3.12+, Git и GitHub CLI. [Патчи](patches/README.md).

**Проверка.** Windows-выпуск от 17 ноября поставляется ZIP размером 2,59 МБ. В выпуске указаны SHA-256, точные исходники и патчи. Для заявленных проверок сборки веса модели не нужны.
