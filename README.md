# Open Terminal AVX1

[Upstream](https://github.com/open-webui/open-terminal) · [ZIP + Install.cmd](https://github.com/aktalascloud/open-terminal-ivybridge-avx1/releases/latest) · [Applied patches](patches/README.md)

Build with Python 3.12+, Git and GitHub CLI: `Build.cmd status`, then `Build.cmd build`. CI and checks are in `.avx1/`. Keep user data, model weights and credentials outside the source checkout.

Независимый Windows-сервис, авторизация с сохранённым ключом, MCP и ограниченный поиск. Сессии и настройки хранятся отдельно.
