# Open Terminal · Ivy Bridge AVX1

[English](README.md) · [Русский](README.ru.md)

Экспериментальная сборка для личных проверок совместимости и производительности. Названия и интерфейс исходного проекта сохранены.

[Исходный проект](https://github.com/open-webui/open-terminal) · [Готовые пакеты](https://github.com/aktalascloud/open-terminal-ivybridge-avx1/releases)

Скачайте единственный актуальный пакет, распакуйте его и запустите `Install.cmd`. `Install.cmd -CheckOnly` проверяет целостность без установки. Конфигурация, ключи, история, кэши и веса моделей в пакет не входят. Модели загружаются с Hugging Face по необходимости.

Одна сборка объединяет свежие официальные исходники и проверенные патчи форка. Разделения на stable/dev нет.

Дополнен русский перевод интерфейса и меню; параметры подстановок проверяются при каждой сборке.

## Замеры

| Показатель | Подтверждённый прирост |
|---|---|
| Скорость генерации LLM | Не измерена |
| JSON на Ivy Bridge | Ожидает сравнения исходной и оптимизированной сборок |
| Производительность на Android | Не измерена на физическом телефоне |

Неизмеренные улучшения не выражаются процентами. Замер JSON относится только к сериализации/разбору, а не к tokens/s. LTO и флаги ISA применяются к указанным нативным компонентам; Python и TypeScript не становятся нативным кодом от этих флагов. AVX2/FMA и fast-math не включаются.

## Лицензии и совместимость

Оригинальные LICENSE, notices и история лицензий сохранены. Каждый бинарный пакет содержит соответствующие исходники. Закрытые ключи подписи хранятся вне репозитория. Для APK используется собственный идентификатор приложения.

Локальное развёртывание дополнительно проверяет частные фильтр и Telegram-бридж владельца. Их исходники, настройки и данные не публикуются. Непроверенные изменения из PR/форков остаются кандидатами; принятые upstream исправления поступают через слияние исходных веток.
