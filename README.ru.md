# Open Terminal AVX1

[English](README.md)

Неофициальный форк: проверенные исправления для агентов/MCP и дополненный русский интерфейс. Один актуальный ZIP + Install.cmd.

[Upstream](https://github.com/open-webui/open-terminal) · [Release](https://github.com/aktalascloud/open-terminal-ivybridge-avx1/releases/latest) · [Patches](.avx1/PATCHES.json)

## Сборка

Нужны Python 3.12+, Git и GitHub CLI для CI. Сборка не зависит от модели, её весов или Codex.

```cmd
Build.cmd status
Build.cmd build
```

`build` проверяет чистоту опубликованного коммита и запускает закреплённый workflow. При готовом локальном компиляторе/SDK: `Build.cmd local`. Зависимости, флаги, тесты и проверки лицензий — в `.avx1/`. Lockfiles и история исходников сохранены. Ключи подписи в репозиторий не входят.

## Установка и проверки

Mainstream 0.16 добавляет браузерные сессии с проверкой владельца, события файлов/портов/процессов и desktop API. Захват и ввод начинаются только по авторизованному запросу API/инструмента; native Windows/macOS используют общий рабочий стол вошедшего пользователя. Windows CDP остаётся на loopback без сетевого прокси. Поиск не открывает устройства/FIFO/сокеты и не пересекает точки монтирования; явно выбранная точка остаётся доступной для поиска.

Режим Proxy переписывает содержимое страниц; для входа в аккаунты и сайтов с изоляцией браузерных origins используйте управляемый Chrome.

`run` учитывает CORS из CLI, окружения и TOML в этом порядке. `mcp --api-key` явно заменяет ключ из окружения, secret-файла или конфигурации; stdio не получает сетевые аргументы.

Используйте единственный пакет релиза. Пользовательские данные храните отдельно от исходников. Адреса серверов и выбор моделей задаются настройками, а не требованиями сборки. Ivy Bridge: AVX/F16C, O3 и проверенный LTO, без AVX2/FMA/PGO/fast-math. Реальные флаги и prebuilt-компоненты указаны в манифесте.

Последние проверки и замеры: [.avx1/measurements/latest.json](.avx1/measurements/latest.json). Микрозамеры CPU не означают скорость LLM. Исходные лицензии и уведомления сохранены.
